# Task 05 — Extended Design Tokens

Objective

Upgrade the design token system to support modern UI surfaces.

Add the following tokens:

ShadowSmall  
ShadowMedium  
ShadowLarge  

CornerRadiusSmall  
CornerRadiusMedium  
CornerRadiusLarge  

GradientPrimary  
GradientBackground

Deliverable

Update DesignTokens.swift.

Rules

Views must not define shadows directly.
Views must not define corner radius directly.
Use tokens instead.
