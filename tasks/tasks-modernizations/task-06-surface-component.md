# Task 06 — Surface Components

Objective

Create reusable surface components to standardize UI layout.

Components

AppCard  
GlassCard  
SectionContainer

AppCard

Rounded surface used for primary content.

GlassCard

Blur-based floating surface used for insights.

SectionContainer

Provides consistent spacing for grouped UI sections.

Rules

Use design tokens for spacing and elevation.
Avoid view-specific styling.
